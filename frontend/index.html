Sherlock

A self-hosted watch marketplace monitor.

Sherlock is being built to watch marketplaces, normalize listings, filter the noise, and alert you when something relevant appears.

View on GitHub ↗

How it will work

From marketplace to signal.

  1. 01

    Monitor

    Will periodically check supported marketplaces.

  2. 02

    Filter

    Will normalize and evaluate listings against your criteria.

  3. 03

    Notify

    Will alert you when something worth seeing appears.

Project status

Starting small.

Sherlock is currently under active development. The first version is focused on watch marketplaces, starting small and expanding gradually.
